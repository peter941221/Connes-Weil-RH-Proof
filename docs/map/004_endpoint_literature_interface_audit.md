## 1. Decision

The active route mixes inherited mathematical machinery with project-specific
interfaces and candidate problems.  The useful distinction is not "old" versus
"new" in the abstract, but the following three labels:

```text
LITERATURE RECONSTRUCTION
    A published mathematical argument or theorem supplies the intended
    mechanism.  The project still owes an exact owner, normalization, and Lean
    certificate, and may have to repair a paper-to-code mismatch.

PROJECT INTERFACE
    The ingredients are known, but the exact healthy-CompactLog statement,
    quantifiers, or same-owner composition is a project construction.

PROJECT CANDIDATE
    The statement or construction is generated by this route and has no
    identified published theorem that discharges it.  This is not a claim that
    no one has ever studied an equivalent statement.
```

The endpoint producer is currently classified as literature reconstruction,
not as a second independently invented RH route.  C3 kernel (a) was a project
candidate after the 1086 `g_3` family was ruled out; record 1087 then
adjudicated it numerically NEGATIVE at the root window (top of arch on the
triple-vanishing subspace at about -0.85 per unit mass, every resolution), so
the root-window candidate is closed as a search target and the surviving
kernel-(a) shape is the same gate at an expanded, orbit-scale window.  Kernel
(b) is a project-created stability wall of one construction method, not a
mandatory logical premise of the final C3 Lean interface; 1087 section 5.2
retires it as a root-window attack line (the feasible set it would have fed is
numerically empty).

## 3. The exact Lean endpoint target

The active exit does not merely request a scalar inequality.  Its current
interface requests a data record for every eligible root-window test:

```lean
structure CC20EndpointTraceCertificate (g : CompactLogTest) where
  coefficient : Real
  trace : Real
  trace_nonnegative : 0 <= trace
  endpoint_bound :
    trace - cc20RankOneBadDirection coefficient g <=
      cc20WInfinityLog g.convolutionSquare
```

For a triple-vanishing root-window test, this certificate implies
`0 <= qw g`.  The rank-one term vanishes at the `0` node; root support makes
the convolution square prime-free; the existing same-owner readback identifies
`cc20WInfinityLog g.convolutionSquare` with `qw g`.

There is an important simplification already in Lean.  A scalar proof

```text
0 <= cc20WInfinityLog g.convolutionSquare
```

for a triple-vanishing `g` is sufficient to construct the record with
`trace = 0`, via `zeroTraceCertificate_of_nonnegative_wInfinity`, once an
in-band `CC20GammaSpectralData` value is supplied.  Triple vanishing kills the
coefficient term, so this degenerate constructor does not need to identify the
paper's spectral gamma: an exact rational in the record's displayed interval
is enough.  No exported canonical witness is currently named.  A supplier of
the scalar sign therefore need not reproduce the paper's nonzero trace package
merely to meet the current endpoint interface.

## 4. External compact-window result: what it does say

[Marcus Chuk, arXiv:2608.24827 (submitted 2026-08-25)]
(https://arxiv.org/abs/2608.24827) is an unreviewed preprint.  Its Corollary 9
states an unconditional interval-certified lower bound

```text
Q(f) >= 8.9e-18 * ||f||_2^2
```

for every complex `f` in `L2(R)` supported in `[-0.8, 0.8]`.  The paper defines
the compact-window profile through the Riemann--Weil quadratic form and its
Hermitian square.  It explicitly describes this as a finite fragment of RH,
not a proof of RH.

The support widths are encouraging but are not an interface proof:

```text
Project base test:  supp g.test subset [-log(2)/2, log(2)/2]
                     log(2)/2 = 0.346573590... < 0.8

External theorem:   supp f subset [-0.8, 0.8]
```

Thus the project base-test window would fit inside the external theorem's
window if `f` is shown to be the same log-coordinate test as `g.test`.

## 6. Consequence for the active route

The current mathematical frontier has two indispensable logical signs:

```text
C3-A:       construct a selected detector with qw g < 0.
Endpoint:   prove qw g >= 0 for that same detector.
```

Record 1087 closed the ROOT-window half of this pair: below radius log 2 / 2
no test satisfies the C3-A sign at all (numerically), and through the trace
balance `qw = -arch` a root-window C3-A witness would itself be an off-line
zero, i.e. ¬RH evidence rather than an RH lemma.  The pair survives only with
both halves moved to the detector's orbit window, where the endpoint half is
exactly the E1--E3 certificate grown outward over the finite visible-prime set
the wider support exposes.  E1--E3 remain the incumbent endpoint producer and
the 2608 import route a potential alternate producer; C3-B stays retired
(record 1087 section 5.2) unless a future formulation reintroduces it.
