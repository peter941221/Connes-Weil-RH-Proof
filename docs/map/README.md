## Evidence labels

- `FORMAL`: checked Lean declaration; cite module, theorem, build log, and
  axiom audit where the record depends on it.
- `LITERATURE-BACKED`: a source has been checked, but the project has not
  formalized the result.
- `PAPER` or `PROJECT CANDIDATE`: internal derivation awaiting formal proof or
  an analytic estimate.
- `NO-GO`: scoped to the hypotheses and owner stated in the record.

experiments in `docs/proofs/`.
