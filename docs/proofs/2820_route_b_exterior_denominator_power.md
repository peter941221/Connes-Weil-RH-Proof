# 2820 Route B exterior denominator power

This record converts the geometric distance lower bound into the reciprocal
power bound used by the exterior envelope.  It is valid for every natural
power `k` once `T > 0`, `T <= t`, and `|y| < T`.

It does not certify the stored node list, D-table, row-B coefficients, tail
constants, cardinal pins, SourceRH, or RH.
