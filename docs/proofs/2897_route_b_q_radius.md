# 2897 Route B centered Q radius

The nearest poles of `tanh(2t/(1-t^2))` solve

`2t/(1-t^2) = i*pi/2`, equivalently
`t^2 + (4 i/pi)t - 1 = 0`.

The two roots have modulus exactly one (numerically both are `1.0`). Thus the
centered variable `Q(t)` has a natural candidate power-series radius `R = 1`,
which comfortably contains the Cauchy radius `0.05`. This record is a pole
location diagnostic; the formal radius and series identity remain open.
