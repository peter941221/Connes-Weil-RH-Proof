# 1668 — Ambient annular columns are already summable

For each fixed pair of radii `N ≤ n` beyond the selected-root support, the
ambient output annulus is the difference of two finite-window output
operators.  Each finite-window output has square-summable columns by the
continuous compact root kernel.  The annular output therefore has
square-summable columns by the positive-trace sum lemma.

This removes the column-summability clause from the ambient annular producer:
the only remaining analytic input is a radius-uniform upper bound on the
total annular square sum.  The full uncut root and RH remain open.
