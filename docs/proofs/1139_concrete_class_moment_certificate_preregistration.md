## 1. Purpose

Records 1137 and 1138 provide the two missing layers of the central
comparison: a pointwise rational approximation to the squared class bump and
an exact integral for every finite sum of powers of `(1 - x^2)⁻¹` on
`[-97/100, 97/100]`. This record assembles those layers into a concrete,
proof-carrying interval certificate for the genuine class moments of orders
`0` and `2`.

The registered comparison is the 35th power of the degree-19 exponential
Taylor polynomial. Its coefficients are generated by exact polynomial
arithmetic, not stored decimal data. The only transcendental endpoint value
is `Real.log (197/3)`; a rational enclosure is proved from exponential
Taylor bounds after splitting
`log (197/3) = 6 * log 2 + log (197/192)`.

The central comparison error is integrated with the elementary constant
envelope supplied by record 1137. The actual endpoint tails are bounded at
radius `97/100` by the same class-bump exponential estimate. The output is
intended to imply the already registered q28 boxes:

```lean
q28Moment0Lo ≤ classMoment 0 ∧ classMoment 0 ≤ q28Moment0Hi
q28Moment2Lo ≤ classMoment 2 ∧ classMoment 2 ≤ q28Moment2Hi
```
