# Proof 775: Metric-Detector Double Corner

## Result

Proof 775 proves an exact source-specific block identity for the current
finite-S Gate owner.  It does not prove Gate 3U.

Let

```text
R = sourceSoninProjection,
C = I-R,
H_S = finiteEulerAmbientGram,
W = detectorOperator.
```

The two boundaries are

```text
M_S = [R,H_S],
D   = [W,R].
```

Lean proves the full ambient identity

```text
M_S D
 = R H_S C W R
   + C H_S R W C.                                    (775.1)
```

The source inclusion kills the second corner.  Therefore the exact Gate
target has the one-corner form

```text
Target_S
 = G_S^(-1) J^dagger H_S C W J,                     (775.2)

G_S=J^dagger H_S J.
```

The declarations are

```text
finiteEulerAmbientGram_comp_detector
finiteEulerMetricDetectorDoubleBoundary_eq_twoCorners
sourceCompression_metricDetectorDoubleBoundary_eq_singleCorner
finiteEulerTargetCommutatorResponse_eq_singleMetricDetectorCorner
```

## Why It Matters

Equation `(775.1)` identifies the actual object that an analytic estimate must
control:

```text
source vector
    |
    v
J --- W --- C --- H_S --- J^dagger G_S^(-1).
```

The detector first crosses from the Sonin range into its complement.  The
complete metric then returns that complement to the source range.  Neither
crossing can be assigned a separate absolute value: doing so recovers the
rejected finite-Euler condition number.

The new first theorem also records the genuine source fact

```text
H_S W = W H_S.
```

Both operators are generated by the same logarithmic translations.  This
commutation does not collapse the corner in `(775.2)`.

## Stronger Abstract Guard

The companion finite certificate uses one two-dimensional block

```text
R = |e_1><e_1|,
v = (e_1+e_2)/sqrt(2),
W = |v><v|,
H_h = h |v><v| + |v_perp><v_perp|,
h > 1.
```

It has

```text
H_h > 0,
W >= 0,
norm(W)=1,
H_h W=W H_h,
norm((J^dagger H_h J)^(-1))<=1.
```

Yet its source corner is

```text
(J^dagger H_h J)^(-1) J^dagger [R,H_h][W,R] J
 = [(h-1)/(2(h+1))].                                 (775.3)
```

Taking `N` orthogonal copies gives trace

```text
N (h-1)/(2(h+1)),
```

which grows linearly in `N`.  Thus projection algebra, metric/detector
commutation, positivity, and a contractive inverse Gram do not produce a
uniform Gate bound.

This is not a counterexample to CCM24/CC20: the block model lacks the actual
real-line compact-root support, the outer/reflected second-support/prolate
completion, and the one-sided finite-Euler translation geometry.  It prevents
only an invalid abstract proof of Gate 3U from `(775.1)`.
