# 1667 — Ambient-output annular domination

The source-compressed annulus is now factored exactly as

```text
compressedAnnulus = sourceInclusion† * ambientOutputAnnulus.
```

The source inclusion is a subtype isometry, so its adjoint is contractive.
Consequently, a uniform total square-sum estimate for the ambient output
annuli implies the existing finite-window root criterion.  The producer form
is explicit: for every sufficiently large `n`, prove a common bound `B` on
their total square sum.

The summability part of that premise is now discharged formally from the
compact continuous-kernel theorem for each finite window and the difference
identity for an annulus (record 1668).  The common bound remains the
analytic obligation.  This does not assert that the uncut root is
Hilbert–Schmidt and does not claim RH.
