# 3298/3299 Route A tight tail and real endpoint bridge

Records 3298 and 3299 repair the named obstruction found by Record 3297.

The old 3285 tail branch used one uniform `exp(-38)` upper bound whenever the
scaled central Taylor branch was unavailable.  Because the owner coefficients
are about `10^14`, that interval was too wide to preserve signed cancellation.
Record 3298 replaces it with a rational, `t`-dependent ladder:

```text
|t/8| <= 1       -> 8th-power Taylor interval
-16 <= t        -> 16th-power Taylor interval
-32 <= t        -> 32nd-power Taylor interval
-64 <= t        -> 64th-power Taylor interval
t < -64         -> exp(-94) tail interval
```

The same record also projects each coefficient-phase rectangle to a real
interval before multiplying by the nonnegative bump interval.  This preserves
the signed real cancellation that the complex rectangle sum had obscured.

The external Decimal diagnostic was run at 80 digits on all 160 block-start
indices (one sample per 256-cell block).  All 160 samples passed the diagnostic
dominance comparison.  The largest sampled gap was about `2.75e-23` at index
12544.  This is evidence for the revised construction only; Decimal arithmetic
is not directed rounding and no sampled row is a Lean theorem.

dominates the formal `record2680CellUpper3209` sum.
