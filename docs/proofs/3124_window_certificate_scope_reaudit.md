## Correction to the old support inference

Record 1408 section 6 properly observes that the healthy detector existence
theorem supplies no fixed small-window field. It then makes a stronger
inference which is invalid: that a large radius used for an upper support
bound proves the actual support is outside the smaller certified window.

```text
known:    support(g) is contained in [-R,R], with R > 0.8
missing:  support(g) is contained in [-0.8,0.8]

invalid:  the known upper containment proves the missing one is false
```

A function supported in `[-0.1,0.1]` satisfies both containments, for any
R>=0.8. This elementary set example explains the inference error; it is
not a substitute detector or a claim about the selected function.

Thus the old "DISJOINT hypotheses" and forced-outside assertions are
withdrawn. The source cannot currently be applied because the necessary
small-support theorem has not been proved, not because that upper bound
alone proves it impossible. The quoted radius construction also gives no
asymptotic `R(rho) ~ 2^gamma`; its prefix index has not been priced that way.

The same distinction governs 3119's stored span bound and the actual
rho-dependent constructions. A conservative large support bound determines
a safe possible prime range. It proves neither an exact support endpoint
nor nonzero samples at any particular omitted prime power.
