# 2881 Route B D4 P interval-cell screen

The exact derivative polynomial `P` is evaluated with outward intervals on
200 owner-correlated cells per outer region. Each cell uses the interval of
`t` together with the endpoint interval of the monotone owner function `z(t)`.

This is a sound cell screen for the polynomial boxes, but it is not yet a
global sign certificate: any undecided cells require a tighter Taylor model
that preserves the t-z correlation.
