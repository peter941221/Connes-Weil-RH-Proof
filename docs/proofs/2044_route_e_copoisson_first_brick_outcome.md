## 3. B1: the Euler-Maclaurin exchange (settled derivation)

With the integer density e^u du in u = log n,

```
sum_{n >= 1} n^{-1/2} f(x - log n)
  ~  integral_0^inf e^{u/2} f(x - u) du
   =  e^{x/2} integral_{-inf}^{x} e^{-y/2} f(y) dy
   =  C_f - e^{x/2} integral_x^{inf} e^{-y/2} f(y) dy.
```

So the discrete lattice realizes the continuous exchange up to the
right-tail remainder, which is identically zero for x >= a_max on
compactly supported f, plus a log-periodic discretization boundary
layer of Euler-Maclaurin type.  Nothing in this identity is circular
with qw: it is the Burnol intertwining restated in the owner's
coordinates, and it is not by itself a sign mechanism.  Its role was to
motivate S; S is now measured generic.
