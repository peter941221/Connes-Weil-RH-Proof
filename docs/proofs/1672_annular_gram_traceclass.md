# 1672 — Fixed annular Gram trace-class owners

For every annulus whose inner and outer radii contain the selected root
support, both the source-compressed annular operator and the ambient-output
annular operator are Hilbert–Schmidt on the named source basis.  The positive
compositions

```text
CompressedAnnular† * CompressedAnnular
AmbientAnnular† * AmbientAnnular
```

are therefore formally `IsTraceClassAlong` that basis.  This uses the exact
finite-window column square-summability already proved and the generic
Hilbert–Schmidt-pair trace-class theorem.

This closes the fixed-annulus ideal-theoretic legality.  It does not provide
the uniform bound as the annulus grows, and does not prove RH.
