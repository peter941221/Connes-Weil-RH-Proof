B5 consumer:


## 2. Registered row set and source protocol

The sole inputs are Round-1 rows R1.1, R3.1, R3.2, R4.1--R4.5, R5.1, and
R5.2 in map 006.  For each row the review retrieves the primary arXiv source,
version history where relevant, references explicitly cited for the mechanism,
and source-visible citations that state a limitation or counterexample.  It
records the earliest relevant result located, but makes no priority claim
beyond the searched citation closure.

Each row receives exactly these two cards:

```text
PRIOR-ART-CARD:
  claimed mechanism; strongest theorem; theorem direction and hypotheses;
  RH-equivalence/conditionality; earliest located source; novelty delta.

B5-TRANSLATION-CARD:
  same CompactLog owner; rho/g quantifiers; support and finite-prime owner;
  exact desired qw/ICgate relation; proposed genuinely new lemma; status.
```

Allowed Beat-2 statuses are `KNOWN`, `NOVEL-BUT-OUT-OF-CORRIDOR`,
`ROUTE-MISMATCH`, and `READY-TO-SCREEN`.  None is a mathematical death.
`READY-TO-SCREEN` requires a precise new lemma and a complete same-owner map;
analogy to a positivity, de Branges, or zero-location theorem is insufficient.

## 3. Anti-circularity and classification checks

For every row, the card must explicitly answer all of the following:

1. Does the source assume RH, assume an equivalent positivity statement, or
   conclude only an equivalence?  If yes, identify the direction needed here
   and why it is absent or new.
2. Does the source's form act on the same `CompactLogTest` convolution square,
   including the finite visible-prime terms?  If not, name the convention and
   owner bridges rather than calling it a transfer.
3. Does the claimed positivity arise independently of `qw >= 0`, RH, or a
   same-g nonnegativity field?  If not, classify it as circular for this
   consumer.
4. Which map-006 evidence class applies to every cited no-go: exact formal
   scope, route policy, or MODEL heuristic?

The source itself is the falsifier: failure to support the card's theorem
direction, owner, or claimed mechanism makes the card `KNOWN`,
`NOVEL-BUT-OUT-OF-CORRIDOR`, or `ROUTE-MISMATCH` as appropriate.  No numerical
test is authorized by this record.
