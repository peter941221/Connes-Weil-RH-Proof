# 2871 Route B D4 symbolic polynomial

The fourth derivative was expanded without interval jet composition. Let
`q = T(u)` and `phi(u) = 1/u - 1/(1-u)`. Since
`q' = -phi' q (1-q)`, repeated symbolic differentiation expresses `T''''`
as `q (q-1) P(u,q) / (u^8 (u-1)^8)`, where `P` is a polynomial of degree 3
in `q` and degree 11 in `u`.

This removes the main dependency source in record 2870: `u`, `phi`, and `q`
can now receive separate interval bounds, and only the explicit polynomial
needs sign certification. The remaining hard step is bounding the logistic
value `q` independently on each rational u interval.

The expansion is generated by
`scripts/route_b_d4_symbolic_polynomial2871.py`. It is an algebraic bridge
diagnostic, not yet a Lean proof.
