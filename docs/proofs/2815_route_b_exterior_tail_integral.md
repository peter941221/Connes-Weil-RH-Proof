# 2815 Route B exterior finite-tail integral

This record turns a pointwise norm bound on a finite exterior interval
`[T,R]` into an interval-integral bound.  It is the consumer needed before
the true improper-tail theorem can be connected to the row-B coefficients.

The theorem keeps the function and the constant explicit.  It does not claim
the row-B constants, an infinite tail, cardinal pins, SourceRH, or RH.
