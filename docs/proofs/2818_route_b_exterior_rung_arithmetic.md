# 2818 Route B exterior rung arithmetic

This record formalizes the degree arithmetic used by the 2729 model audit for
the 55-factor correction with power 2.  The exterior degree is
`57 - 10*k`; it is positive for rungs `k <= 5` and at most `-3` from rung 6.

This is only exponent arithmetic.  It does not prove the D-table bounds,
row-B coefficients, tail constants, cardinal pins, SourceRH, or RH.
