# 2814 Route B exterior monomial bound

This record formalizes the monotonicity brick used by the D7 exterior tail.
For a positive tail threshold `T`, `x >= T`, nonnegative coefficient `C`, and
natural decay order `q`, the scaled monomial `C * x^(-q)` is bounded by its
value at `T`.

The row-B coefficients, node-distance factors, eligible rung choice, and the
integral/summation assembly remain separate obligations. No cardinal pin,
SourceRH, or RH claim is made.
