# 1637 — fixed-scale compact-observable probe and the bump-section no-go

Date: 2026-09-18

Status: numerical research record only. This record serves the formal
compact-observable interface of 1636, but it does not instantiate its
producer and does not claim carrier nontriviality or RH.

## 1. Question tested

The 1636 theorem applies to one fixed defect operator `D`. Therefore a valid
producer needs a sequence `x_K` with

```text
D x_K -> 0  as K -> infinity
```

at one fixed `lambda`, together with a fixed compact observable `K` for which
`K x_K` does not tend to zero. A decrease caused only by changing `lambda`
does not satisfy this hypothesis.

The new probe extracts the smallest generalized eigenvector of the actual
Toeplitz finite section and measures it with a fixed rank-two compact
observable whose range is spanned by the rational Hardy vectors with spatial
profiles `h_3` and `h_4`. These probes are not the expanding compact-bump
translate section.

## 2. Readback

For `lambda = 0.1`, the section minimum and fixed-observable mass are:

```text
K        1          2          4          8          16         48
sigma    3.0304e-6  3.0288e-6  3.0272e-6  3.0237e-6  3.0236e-6  3.0235e-6
mass     9.2010e-2  9.1900e-2  9.1905e-2  9.1925e-2  9.1925e-2  9.1925e-2
```

For `lambda = 0.2`, the corresponding section minimum stabilizes at about
`1.2377e-3`, while the fixed-observable mass stabilizes at about `9.655e-2`.
The same qualitative pattern occurs at `lambda = 0.5` and `lambda = 1/e`.

The eigenvector therefore retains a fixed compact-observable component, but
the defect does not continue to zero as the section grows. The small defect is
already present in the first vector and is a scale effect, not a fixed-scale
approximate-kernel sequence.

## 3. Route ruling

This probe rules out the following invalid inference:

```text
defect(lambda) -> 0 as lambda -> 0
    ==> carrier(lambda0) is nontrivial for some fixed lambda0.
```

It does not rule out the carrier. It says that the current compact bump
translate family is too poor to produce the 1636 witness at fixed scale. The
next permitted producer must use a richer fixed-scale family, such as varying
widths or algebraic-tail rational vectors, and must track both:

```text
fixed-lambda defect -> 0,
fixed compact-observable mass stays positive.
```

Rows at the FFT floor are not interpreted as zero defects.

## 4. Reproducibility

The script is `scripts/carrier_compact_observable_1637.py`. It uses the same
FFT convention and real multiplier as the 1630--1635 probes. The fixed
observable is rank two, generated by the rational `k=3` and `k=4` profiles.
