## 3. New antibodies (registered this record)

```
DH (Davenport-Heilbronn, 1936): a mechanism whose hypotheses are met
   by Riemann-type functions with a functional equation but off-line
   zeros is dead unless it uses MORE than the functional equation.
   Fires against: "FE-only" imports, universality-of-FE arguments.
   Note: the Weil-positivity route itself does use more than FE (the
   prime/archimedean explicit data), so DH does not touch the
   mainline - it fires only against FE-alone stowaways.

RT (Rodgers-Tao, arXiv 1801.05914): Lambda >= 0.  Fires against:
   any mechanism that needs a positive margin at a de Bruijn-Newman
   time BEYOND the conjectured 0, or that needs positivity with
   slack in a window whose closure would also give Lambda < 0, when
   the mechanism is not identity-exact.  Equivalently: no-margin
   rule - at the correct time parameter every inequality must be
   tight/exact; "improve the constant until it works" cannot work.
```

Both are consistency antibodies for the VAC class: they reject
mechanisms that would prove too much, exactly as 1411 rejects
mechanisms true only where the target is trivial.
