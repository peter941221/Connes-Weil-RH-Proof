Date: 2026-09-19.

Status: formal no-go; RH is not claimed.

of the off-diagonal Hardy factor to square-summable columns of the actual
ambient leakage leg. Record 1512 formally proves that the latter is not
Hilbert--Schmidt on any Hilbert basis at unit scale whenever the selected
source Laplace value is nonzero. Therefore the 1654 premise is impossible in
that regime. The new theorem closes the tempting but false global-HS route.

finite visible-prime quadratic-energy estimate, not a full-basis
