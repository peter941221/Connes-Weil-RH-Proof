# 1669 — Annular Gram trace interface

The ambient annular energy now has an exact positive-operator form.  Define

```text
Gram(N,n) = AmbientAnnular(N,n)† * AmbientAnnular(N,n).
```

For every named source basis, its ordinary diagonal trace is exactly the
complexification of the ambient annular column-energy series.  Thus the
remaining uniform estimate can be supplied either as a real square-sum
bound or as a uniform ordinary trace bound for these positive Gram operators.

The identity is formal and axiom-clean; it does not prove the uniform trace
bound or RH.
