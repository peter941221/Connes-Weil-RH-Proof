## The reduction (the judgment this record exists for)

For the extracted table, CC20 Fact 1's half-gap certificate is reduced to
exactly two analytic caller fields, both about the endpoint side:

- `hchi`: ROOT-window continuity of `endpointDisplacementProfile`, i.e. of
  `qEpsilon(e^|v|) / (2 * endpointSlope)`.  Supplying it needs a CONCRETE
  `CC20EndpointSpectralData` instance (eigenvalues, analytic modes, slope)
  with an analytic enclosure on `e^|v|` in `[1, 2]`.  No such instance
  exists in the repo, and the paper itself states the endpoint side only
  asymptotically.
- `hmass`: the strict inequality
  `2 * integral_[0, log 2] |chi - tau| <= epsilon1`.  With `tau` concrete
  this becomes a certified L1 quadrature problem over 3464 paired Fourier
  terms against the enclosed `chi`.  The paper's `~ 0.00122` is an
  asymptotic decimal, not a bound; no certificate is claimed here, and
  storing one as data would violate the integrity rules.  The `yoshida_intervals`
  engine pattern (exact rationals out, per-node provenance, Lean verifies
  the aggregate) is the intended shape.

Everything structural is closed: after 1044, the ONLY unknowns between the
published tables and the equation-(121) consumer are the two fields above.

## Engineering notes

- A literal-per-branch `match` on 1732 `Fin` cases burns the default
  heartbeat budget inside the match compiler (`timeout at whnf`); a deep
  if-then-else chain on `n.val` elaborates linearly, and needs
  `maxRecDepth` raised as well (default 512 < 1732).  The proofs never
  evaluate the table - only the `Bool` sign slot - so the chain is never
  forced.
- Structure-projection arguments need their own parentheses in application
  position (`f ((s a).field i)`, not `f (s a).field i`): application is
  left-associative and the bare projection is swallowed as the first
  argument.
- The Pi-sum-to-pointwise bridge (`Finset.sum_apply` via a funext'd
  `have`, then rewrite) is required TWICE in this slice: once for the
  profile sum inside `ContinuousOn`, once per profile term.  Same lesson as
  the ExpMass session, item 15.
