# 3083 - Gate 1 joint-symbol numerical screen

The exact 3080 scalar formula was evaluated with 80-digit mpmath arithmetic
for several finite prime sets. The joint symbol is negative at xi = 0 for all
screens because the prime Poisson contributions are positive there and the
archimedean term is also subtracted. This is routing evidence, not a Lean
certificate: the actual owner transform may vanish at zero, and the screen
cannot exclude a joint factorization after a nontrivial square rearrangement.

The reproducible script is `tmp/gate1_joint_screen_3083.py`; output is in
`results/3083_gate1_joint_screen.txt`.
