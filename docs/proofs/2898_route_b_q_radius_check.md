# 2898 Route B centered Q radius check

For the nearest-pole quadratic `t^2 + i b t - 1 = 0`, the product of the two
conjugate roots is `-1`. Their moduli are equal, so each root has modulus one.
The selected working radius is `R = 1/20`, and the exact rational comparison
`1/20 < 1` passes.

This closes the algebraic radius-selection check. It does not prove the full
analytic convergence theorem or the equality between the power series and the
real logistic function.
