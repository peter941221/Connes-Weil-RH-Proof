## 2. A legal one-prime Julia step with zero transfer

Fix `0<a<1`, later specialized to `a=p^(-1/2)`, and put

```text
s = sqrt(1-a^2),
P_0 = |e_0><e_0|,

U_a = [[ a, -s],
       [ s,  a]].                                    (ZG.2)
```

`U_a` is unitary (orthogonal over the reals), and

```text
det(I-a U_a) = 1-a^2 > 0.                            (ZG.3)
```

Thus it is an allowed one-factor transport in Proof 350.  Relative to
`Ran(P_0) direct_sum Ran(I-P_0)`, its scalar blocks are

```text
U_00=a,  U_01=-s,  U_10=s,  U_11=a.
```

The graph and transfer formulas from `(JG.4)` and `(JG.6)` give

```text
X_a = a (1-a^2)^(-1) s = a/s,

Phi_a
 = a + a(-s)(1-a^2)^(-1)s
 = 0.                                                (ZG.4)
```

The transported line is the graph of `X_a`, generated by

```text
v_1 = s e_0 + a e_1.                                (ZG.5)
```

The normalized range sine is exactly

```text
|X_a| / sqrt(1+|X_a|^2) = a.                        (ZG.6)
```

So the one-prime square gain is not merely respected; it is sharp:

```text
S_a* S_a = a^2 = a^2/(1-a^2) (I-Phi_a* Phi_a).      (ZG.7)
```

Nevertheless the first chronological Julia prefix is

```text
Psi_1 = Phi_a = 0.                                  (ZG.8)
```

This shows why invertibility of the ambient `I-aU` does not make the
compressed Julia transfer invertible.  The latter is a Schur/transfer
function of the current range, not the ambient Euler factor.

## 3. A nonzero completed corner after the zero prefix

Apply the same construction once more, now relative to the transported line
`Ran(P_1)=span(v_1)`, but with a distinct visible prime `q` and
`b=q^(-1/2)`.  Let `P_2` be its Gram-corrected next range.  The second pair has
a canonical midpoint `M_2` and off-diagonal innovation

```text
R_2 = (I-M_2)(P_2-P_1)M_2.                           (ZG.9)
```

The one-dimensional midpoint geometry gives

```text
norm(R_2) = b.                                      (ZG.10)
```

Choose unit vectors `u` and `v` spanning `Ran(M_2)` and `Ran(I-M_2)`, with
the phase of `v` fixed so that

```text
R_2 = b |v><u|.                                     (ZG.11)
```

Now choose the rank-one root

```text
C = |u><u+v|,
W = C* C = |u+v><u+v|.                              (ZG.12)
```

This is compact in the strongest finite-dimensional sense.  Its completed
midpoint corner is

```text
L_2 = M_2 C* C (I-M_2) = |u><v| != 0.               (ZG.13)
```

The exact two-root midpoint identity then has a nonzero scalar:

```text
Tr(W(P_2-P_1))
 = 2 Re Tr(L_2 R_2)
 = 2b != 0.                                         (ZG.14)
```

But `(ZG.8)` makes every attempted Proof 770 factorization at the second
step vanish identically:

```text
U_2^mid Psi_1 A_root B_2* = 0 != L_2.               (ZG.15)
```

The obstruction is not an ideal-class issue.  It remains if `A_root` and
`B_2` are arbitrary bounded, finite-rank, Hilbert--Schmidt, or trace-class
operators.  The prefix is zero before any of those choices are made.

## 4. What this does and does not rule out

The construction satisfies every generic ingredient used to obtain the Julia
range ledger:

```text
unitary translation surrogate;
actual Euler-sized coefficient a=p^(-1/2);
boundedly invertible ambient Euler factor;
exact graph range and Gram normalization;
sharp post-Gram range-sine square gain;
canonical midpoint off-diagonalization;
positive detector W=C* C with a rank-one root;
ordinary finite-dimensional trace legality.
```

It does not include the actual real-line half-line/scattering/prolate source
geometry.  Consequently it does not say that CCM24's complete physical corner
`L_j` violates `(ZG.1)`.  It establishes the exact logical boundary:

```text
generic Julia graph geometry + compact root
    does not imply
completed physical prefix factorization.             (ZG.16)
```

The needed source theorem must therefore prove at least one genuinely new
property on the actual carrier:

```text
1. physical annihilation of every prefix-loss direction, namely

   ker(A_root* Psi_(j-1)*) subset ker(Ltilde_j*);

2. the stronger bounded, ideally Hilbert--Schmidt, lift in `(ZG.1)`;

3. or a different signed endpoint representation which never factors through
   the Julia prefix.
```

The first item is only visibility.  As Proof 771 records, even it does not
construct a bounded lift when the prefix range is nonclosed.

## 5. Consequence for Proofs 770--772

Proof 772's signed row trace is correctly invariant under changes between
*existing bounded lifts*.  The zero-transfer example has no nonzero bounded
lift at all.  Lift invariance cannot manufacture a lift where the prefix has
annihilated the completed physical corner.

Therefore the following inference is invalid:

```text
Julia Bessel contraction
  + compact root corner
  -> choose a bounded prefixed lift
  -> Gate 3U row trace.                              (ZG.17)
```

The valid order remains:

```text
actual physical outer/reflected-second-support/prolate cancellation
  -> prove the source-specific lift or another signed trace owner
  -> only then invoke the Julia row.                 (ZG.18)
```

This leaves the relative determinant / stopped physical-boundary route of
Proofs 262 and 266 intact.  That route does not obtain its source owner by
cancelling a Julia prefix.
