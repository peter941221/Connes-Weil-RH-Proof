# Archived Routes

This directory contains work that is preserved for provenance but is not part
of the active RH proof route. Nothing under `archive/` is a default Lean target.

The active route and its freeze rules are defined in
`RH_MAINLINE_FREEZE.md`. A historical artifact may be restored only under the
unfreeze rule in that document. In particular, a diagnostic bound or numerical
result is not an RH implication merely because it is axiom-clean.

## Contents

- `diagnostic_gate3u/`: finite-band and infinite-carrier Gate-3U context.
- `diagnostic_lane_r/`: Lane-R/Gamma_R prefix sign experiments.
